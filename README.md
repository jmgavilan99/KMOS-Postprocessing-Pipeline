# KMOS Post-Processing Pipeline

This repository contains the full post-processing chain used to extract
stellar spectra from KMOS IFU data cubes. Starting from already-reduced
data cubes (produced by the **EsoReflex** enviroment (Freudling et al. 2013, 
A&A, 559, A96)), it performs sky subtraction, automatic and manual astrometric 
correction, and 1D spectral extraction for every star detected inside the IFUs.

Below you will find a summary of each Python script and the role it plays
in the pipeline, followed by installation and usage instructions.

## Pipeline Stages

| Step | Script | Purpose | Input | Output |
|------|--------|---------|-------|--------|
| 1 | `01_sky_subtraction.py` | Subtract sky from each OB cube using `kmos_sky_tweak` + `kmos_combine` | Reduced `SINGLE_CUBES_KMOS` cubes | Sky-subtracted cubes (`SKY_TWEAK` → combined) |
| 2 | `02_auto_astrometry.py` | Automatic astrometric correction | | |
| 3 | `03_manual_astrometry.py` | Manual (interactive) astrometric correction | | |
| 4 | `04_extract_spectra.py` | Extract 1D spectra | | |

---

### 1. Sky Subtraction — `01_sky_subtraction.py`

Subtracts the sky background from each **OB** (observation block) cube using the ESO
recipe `kmos_sky_tweak`, then combines the resulting tweaked cubes with
`kmos_combine`.

**What the script does**

1. For a given pointing (e.g. `P1`) and a list of concatenation folders (e.g. `con1`, `con2`…), it locates the reference **sky** cube inside a `Sky/` subfolder.

2. It then discovers every **OB** subfolder inside each concatenation and finds the corresponding `*SINGLE_CUBES_KMOS*.fits` science cube.

3. For each OB it:

   - Creates a clean output folder `sky_tweak/`.

   - Writes a `single_cubes.sof` file. An example of its content is:

            object_cubes/P1_OB1_SINGLE_CUBES_KMOS.2025-05-24T05:40:08.954.fits OBJECT_CUBE 
            sky_cubes/Sky_SINGLE_CUBES_KMOS.2025-05-24T06:14:02.240.fits SKY_CUBE
            
    
   - Runs `esorex kmos_sky_tweak single_cubes.sof`. This recipe removes the **OH sky emission lines** and thermal background, producing a corrected object cube (`SKY_TWEAK.fits`) that contains all IFUs.

   - Writes a `decombine.sof` file pointing to the resulting `SKY_TWEAK.fits`. An example of its content is:

            single_cube/SKY_TWEAK.fits SINGLE_CUBES
            
    -   Runs `esorex kmos_combine --method=header decombine.sof`. This
        recipe shifts and combines the exposures. The output is a combined
        data cube (`COMBINE_*`) where the individual IFU spectra are
        separated and the final astrophysical flux units (e.g.
        `erg cm⁻² s⁻¹ Å⁻¹`) are applied.

**Configuration (top of the script)**

| Variable | Meaning |
|----------|---------|
| `pointing` | Pointing name, e.g. `"P0"`, `"P1"` |
| `cons` | List of concatenation folders to process, e.g. `["con1", "con2"]` |
| `SKY_FOLDER` | Name of the sky subfolder inside each concatenation (default `"Sky"`) |
| `base_path` | Root path to the reduced data |
| `ESOREX` | Full path to the `esorex` executable |

        
**Input**

<base_path>/
├── con1/
│   ├── Sky/   -> reduced sky cube (EsoReflex, dark cloud ~20' away)
│   ├── OB1/   -> reduced science cube (EsoReflex)
│   └── OB2/   -> ...
└── con2/ ...

 Each *SINGLE_CUBES_KMOS*.fits file must live inside: <folder>/<date>/KMOS.*_tpl/`

**Output**

Inside each `OB*/` folder, the script creates a `sky_tweak/` subfolder with the following files:

- `single_cubes.sof` — SOF file listing the science and sky cubes used as input to `kmos_sky_tweak`.
- `SKY_TWEAK.fits` — sky-subtracted object cube (all IFUs) produced by `kmos_sky_tweak`.
- `decombine.sof` — SOF file listing `SKY_TWEAK.fits` as input for `kmos_combine`.
- `COMBINE_*.fits` — final combined data cube produced by `kmos_combine`. The individual IFU spectra are separated and the flux is in astrophysical units (e.g. `erg cm⁻² s⁻¹ Å⁻¹`). The exact filename is generated by the ESO recipe.

Directory structure:
OB1/
└── sky_tweak/
    ├── single_cubes.sof
    ├── SKY_TWEAK.fits
    ├── decombine.sof
    └── COMBINE_*.fits


**Notes / caveats**

- `os.chdir()` is used inside the script; make sure you don't have other
  code relying on the working directory afterwards.
- Directories named `sky_tweak` and `tmp` are ignored when searching for
  cubes to avoid picking up previous outputs.
- Any OB whose cube cannot be found is skipped with a printed error, so a
  partial run never aborts the whole loop.
